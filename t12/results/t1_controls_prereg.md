# T1′ 통제 분석 사전 고정 (2026-10-09, 결과 확인 전 작성)

외부 검토 4건(①문장 단위 CV, ②소수 쌍·대응 재표집, ③정렬·양식·고정창, ④어중/어말 구성·유성/무성 분리)을 반영한 재분석의 가설·주분석·판정 기준을 실행 전에 고정한다. 실행 스크립트 `code/run_t1_controls.py`.

## 가설
H1: 어두 → 비어두(어중+어말)에서 후두 대립(P/B·T/D·K/G)의 신경 분리도 감소가 조음위치 대립(P/T·T/K·B/D·D/G)보다 크다.
효과량 D = Δ_place − Δ_lar, Δ = acc(비어두) − acc(어두). D > 0이면 H1 방향. (기존 보고 D = 0.109)

## 주분석 (사전 지정 1개)
- 자료: 발성(vocal) 세션만, RNN 미학습 구간(held_out = test 파티션 + 미학습 세션 07.29 전체), 6v 128채널, seg 창, score ≥ 0.5.
- 분류: PCA 30(폴드 내) → 수축 LDA, 5폴드 StratifiedGroupKFold × 10반복, **그룹 = 문장 시행**(session|partition|trial_idx).
- 표집: 쌍별로 어두·비어두 n을 맞춤(≤300/class). 비어두는 두 클래스의 **어중:어말 구성을 같게** 맞춤.
- 쌍: 후두 3쌍·위치 4쌍 사전 지정. 마찰음 후두쌍 F/V·TH/DH는 무기식 대조군.

## 통계 (주분석에 모두 적용)
1. 쌍 대응 유지 재표집 CI: 쌍을 단위로 재표집하되 한 쌍의 어두·비어두 값을 함께 움직임.
2. 쌍 라벨 정확 순열 p: 7쌍 중 어느 3쌍이 후두쌍인지 라벨을 전부 열거(C(7,3)=35, 최소 p=.029). 보조 지표.
3. **구간 수준 위치 라벨 순열 p (200회)**: 쌍·클래스 안에서 어두/비어두 라벨을 섞고 같은 그룹 CV로 D를 재계산. 쌍 수에 의존하지 않는 주 검정.
4. 20회 독립 균형 재표집: 쌍별 Δ의 분포(표집·CV 잡음), 반복 간 D의 2.5–97.5 백분위.
5. 쌍 하나씩 제외(후두·위치 모두)한 D.

## 판정 기준
- 지지: (3) p < .05 **그리고** (5) 모든 제외에서 D > 0.
- 약한 지지: (3) p < .05이나 특정 쌍 제외 시 D ≤ 0 → "쌍 의존적"으로 보고.
- 불지지: (3) p ≥ .05. 효과는 보고하되 주장하지 않음.

## 사전 명시 민감도 (주장에 쓰지 않고 방향 일치만 보고)
test 파티션만 / 발성 전체(pooled) / 블록 그룹 CV / 세션 그룹 CV / 단어 상한 20 / 단어 그룹 CV / 80 ms 고정 중심창 / 3수준 분리(어두·어중·어말, 구성 문제 없음) / 유성·무성 위치쌍 분리 / 후두 6쌍 vs 위치 9쌍 / 이전 설정 재현(모든 양식·무작위 CV·구성 비균형) = 코드 회귀 확인.

## 탐색적(주결론에서 분리)
계획 창(pre100·pre300), 시간전개 피크, 교차 위치 해독(통제 통과 후 추가).
