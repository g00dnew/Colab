These files were generated with our example speech decoding code released here: https://github.com/fwillett/speechBCI. They are provided for convenience so that you do not have to run intermediate steps, and for documentation of what the output of the code should look like. The "rnns" folder contains an example RNN baseline decoder, and the "tfRecords" folder contains Tensorflow v2 .tfrecord files that were formatted for training and evaluating the RNN decoder. 

--rnns/baselineRelease--

This folder contains files generated during RNN training. 

The "ckpt-" files are Tensorflow checkpoint files that contain the RNN weights generated during training. They were generated with our example notebook https://github.com/fwillett/speechBCI/blob/main/AnalysisExamples/rnn_step2_trainBaselineRNN.ipynb and are loaded by our example notebook https://github.com/fwillett/speechBCI/blob/main/AnalysisExamples/rnn_step3_baselineRNNInference.ipynb. 

"args.yaml" defines the RNN parameters/arguments used for training. 

"outputSnapshot" is a .mat file that our code creates during training to save variables useful for examining the training procedure. It contains the following variables. "perBatchData_train" and "perBatchData_val" are 10001x6 tables where each row contains information about a single minibatch. The first column is the batch index, the second is the time that batch took to compute, the third contains the prediction loss for that minibatch, the fourth contains the regularization loss, the fifth contains the phoneme error rate, and the sixth contains the gradient norm. "logitsSnapshot" is a S x 41 matrix containing the logits output by the RNN for a single example trial (where S is the number of RNN steps, and there are 41 outputs). "inputFeaturesSnapshot" contains the corresponding input neural features (of dimension T x 256, where T is the number of time steps and there are 256 features). "seqIDs" is a vector of integers containing the sequence of phonemes for that example trial. 

"events.out.tfevents" files are generated by Tensorflow during training for visualizing the training procedure with TensorBoard.

"main.log" is an (empty) log file 

--rnns/tfRecords --

This folder contains .tfrecord files for RNN training and evaluation. They were generated with our example notebook https://github.com/fwillett/speechBCI/blob/main/AnalysisExamples/rnn_step1_makeTFRecords.ipynb. Each subfolder corresponds to a single day of data (e.g., "t12.2022.04.28" contains the .tfrecords for the data collected on 2022/04/28). Within each day, there is a "train", "test" and (optionally) a "competitionHoldOut" folder. Within these folders are single .tfrecord files named "chunk_0.tfrecord" that contain data samples (our code was setup to ingest multiple file chunks per day, but the data was small enough not to need this feature, so all files are named "chunk_0"). 

The "train" folders contain data samples used for training the RNN, the "test" folder contains data samples used for evaluating the RNN performance during training, and the "competitionHoldOut" holder contains data samples used for the speech decoding competition we intend to hold. These samples do not contain labels. 

The .tfrecord files are created and used by our code (https://github.com/fwillett/speechBCI) and contain the following variables:

datasetFeatures = {
	"inputFeatures": tf.io.FixedLenSequenceFeature([nInputFeatures], tf.float32, allow_missing=True),
	"newClassSignal": tf.io.FixedLenSequenceFeature([], tf.float32, allow_missing=True),
	"ceMask": tf.io.FixedLenSequenceFeature([], tf.float32, allow_missing=True),
	"seqClassIDs": tf.io.FixedLenFeature((maxSeqElements), tf.int64),
	"nTimeSteps": tf.io.FixedLenFeature((), tf.int64),
	"nSeqElements": tf.io.FixedLenFeature((), tf.int64),
	"transcription": tf.io.FixedLenFeature((maxSeqElements), tf.int64)
} 

Here, nInputFeatures=256 and maxSeqElements=500. This python code snippt can be used to load the .tfrecord file using the function tf.io.parse_single_example. 

"inputFeatures" are the neural features corresponding to a single trial and is of dimensionality T x N, where T is the number of time steps and and N is the number of input feautres (256). "newClassSignal" was not used for this particular example, but is a T x 1 vector that was intended to store a time series signal that goes high whenever a new phoneme begins. "ceMask" was also not used for this example, but is a T x 1 vector that was intended to store an error mask. "seqClassIDs" defines the phoneme sequence and is a 500-element list, where each entry contains the integer ID of a phoneme. "nTimeSteps" is a scalar value that defines how many time steps are in the example. "nSeqElements" is a scalar value that defines how many phonemes are in the sequence. "transcription" is an ASCII transcription of the sentence and is a 500-element list, where each entry is a character.
